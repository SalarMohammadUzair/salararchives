# SalarArchives

A personal digital garden — a collection of my notes, thoughts, and writing published as an interconnected website. Built with Quartz v4.

🌐 **Live site:** [salararchives.vercel.app]([https://salarmuzair.tech](https://salararchives.vercel.app/))

## What's here

This garden contains notes on topics I'm actively thinking about: Homelabbing, self hosting services and relying less on big tech. It's less a polished blog and more a working record of ideas in progress. 

## Running your own instance

This repo is built on top of [Quartz v4](https://quartz.jzhao.xyz/). If you want to spin up your own digital garden, follow the Quartz documentation linked below.
